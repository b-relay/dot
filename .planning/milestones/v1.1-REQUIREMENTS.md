## v1.1 Requirements

Requirements for making dotfiles portable across Mac architectures.

### Config Portability

- [x] **PORT-01**: `zsh/zprofile` dynamically detects Homebrew location (Apple Silicon or Intel)
- [x] **PORT-02**: `zsh/plugins/fzf.zsh` uses `$(brew --prefix)` instead of hardcoded paths
- [x] **PORT-03**: `zsh/config/completions.zsh` uses dynamic bun path (no hardcoded version)

### Architecture Detection

- [x] **ARCH-01**: `dot doctor` detects current Mac architecture (arm64 vs x86_64)
- [x] **ARCH-02**: `dot doctor` scans zsh config files for wrong-architecture Homebrew paths
- [x] **ARCH-03**: `dot doctor` reports mismatched paths with file location and suggested fix
- [x] **ARCH-04**: Claude analysis prompt includes architecture context for deeper insights

### Recommended Dependencies

- [x] **RDEP-01**: `dot doctor` checks if JetBrains Mono Nerd Font is installed and recommends it if missing
