# Milestone v1.1: Architecture Portability

**Status:** ✅ SHIPPED 2026-01-26
**Phases:** 4-5
**Total Plans:** 2

## Overview

This milestone delivered architecture portability for dotfiles across Apple Silicon and Intel Macs. Phase 4 fixed hardcoded Homebrew paths in zsh config files to use dynamic detection. Phase 5 added architecture detection to `dot doctor` so it can warn users about wrong-architecture paths.

## Phases

### Phase 4: Config Portability

**Goal**: Users can use dotfiles on both Apple Silicon and Intel Macs without manual path changes
**Depends on**: Nothing (first phase of v1.1)
**Requirements**: PORT-01, PORT-02, PORT-03
**Plans**: 1 plan

Plans:
- [x] 04-01-PLAN.md — Make zsh config portable across Mac architectures

**Success Criteria** (all met):
1. ✓ User on Intel Mac can source zsh config without errors from missing Homebrew paths
2. ✓ User on Apple Silicon Mac can source zsh config without errors from missing Homebrew paths
3. ✓ fzf keybindings and completions load regardless of Homebrew location
4. ✓ Bun completions load regardless of installed bun version

**Files Modified:**
- `zsh/zprofile` - Dynamic Homebrew initialization
- `zsh/plugins/fzf.zsh` - Architecture-portable fzf setup
- `zsh/config/completions.zsh` - Version-independent bun completions

### Phase 5: Architecture Detection

**Goal**: Users are warned by `dot doctor` when zsh config files contain architecture-specific Homebrew paths
**Depends on**: Phase 4 (patterns established for what to detect)
**Requirements**: ARCH-01, ARCH-02, ARCH-03, ARCH-04, RDEP-01
**Plans**: 1 plan

Plans:
- [x] 05-01-PLAN.md — Add architecture detection, path scanning, and font checking to doctor

**Success Criteria** (all met):
1. ✓ User runs `dot doctor` and sees current Mac architecture (arm64 or x86_64) displayed
2. ✓ User with hardcoded `/opt/homebrew` paths on Intel Mac sees warning with file location
3. ✓ User with hardcoded `/usr/local` paths on Apple Silicon sees warning with file location
4. ✓ Claude analysis includes architecture context when analyzing the setup
5. ✓ User without JetBrains Mono Nerd Font sees recommendation to install it

**Files Modified:**
- `dot/index.ts` - Architecture detection, path scanning, font checking

---

## Milestone Summary

**Key Decisions:**
- Check /opt/homebrew first then /usr/local for Homebrew detection (matches Homebrew preference)
- Cache FZF_PREFIX to avoid multiple $(brew --prefix) calls
- Use brew --prefix bun for version independence
- Use process.arch for architecture detection (native to Bun/Node)
- Run font check in parallel with dependency checks

**Issues Resolved:**
- Hardcoded /opt/homebrew paths broke on Intel Macs
- Hardcoded bun Cellar paths broke on version updates

**Technical Debt Incurred:**
- None
