# Milestone v2.0: Standalone CLI

**Status:** ✅ SHIPPED 2026-02-01
**Phases:** 6
**Total Plans:** 5

## Overview

This milestone decoupled the dot CLI from the dotfiles repo structure. The CLI now works independently with configurable links, configurable dotfiles location, and can be installed as a standalone binary without requiring the dotfiles repo as a submodule.

## Milestone Summary

**Key Decisions:**
- JSON as primary config format (works with compiled binary)
- State file at ~/.config/dot/state.json for dotfiles path persistence
- Priority chain: --dotfiles flag > DOT_HOME env > state file > ~/.dotfiles fallback
- @clack/prompts for wizard UI (better UX than bun-promptx)
- Deep symlink scanning (3-4 levels) for discovery
- fs.rename first, copy+delete fallback for cross-device moves

**Issues Resolved:**
- Hardcoded LINKS map made repo structure rigid
- No way to use dot CLI without cloning dotfiles repo
- No discovery of existing dotfile symlinks

**Technical Debt Incurred:**
- Self-update from GitHub releases not yet implemented (shows manual instructions)
