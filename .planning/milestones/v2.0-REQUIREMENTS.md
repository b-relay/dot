## v2.0 Requirements

Requirements for decoupling the dot CLI from the dotfiles repo structure.

### CLI Decoupling

- [x] **DECOUPLE-01**: User can configure symlink mappings via external config file (dot.config.json)
- [x] **DECOUPLE-02**: User can specify dotfiles directory location (--dotfiles flag, DOT_HOME env, state file)
- [x] **DECOUPLE-03**: dot CLI can be installed standalone (compiled binary)
- [x] **DECOUPLE-04**: Removing dot as submodule from dotfiles repo doesn't break anything

### Init Wizard

- [x] **INIT-01**: User running dot for first time gets interactive init wizard
- [x] **INIT-02**: Wizard discovers existing symlinks pointing to dotfiles repo
- [x] **INIT-03**: Wizard detects broken symlinks and reports them
- [x] **INIT-04**: Wizard generates dot.config.json from discovered mappings

### Link Command

- [x] **LINK-01**: User can add new dotfiles with `dot link <path>` command
- [x] **LINK-02**: Interactive folder selection for destination in repo
- [x] **LINK-03**: --as flag for non-interactive destination specification
- [x] **LINK-04**: Config file updated with new link mapping

### Move Command

- [x] **MOVE-01**: User can relocate dotfiles with `dot move --self <path>` command
- [x] **MOVE-02**: All symlinks updated to point to new location
- [x] **MOVE-03**: State file updated with new dotfiles path
- [x] **MOVE-04**: Confirmation prompt before destructive operation

### Distribution

- [x] **DIST-01**: Standalone compiled binary (bun build --compile)
- [x] **DIST-02**: Version flag (--version, -v)
- [x] **DIST-03**: Update command with manual instructions
