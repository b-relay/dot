<task type="auto">
  <name>Task 2: Make fzf.zsh use dynamic brew prefix</name>
  <files>zsh/plugins/fzf.zsh</files>
  <action>
Replace the entire fzf.zsh content. Current file has hardcoded `/opt/homebrew/opt/fzf` paths.

New content using `$(brew --prefix)`:
```zsh
# Setup fzf
# ---------
# Only configure if fzf is installed via Homebrew
if command -v brew &>/dev/null && [[ -d "$(brew --prefix)/opt/fzf" ]]; then
  FZF_PREFIX="$(brew --prefix)/opt/fzf"

  # Add to PATH if not already present
  if [[ ! "$PATH" == *"$FZF_PREFIX/bin"* ]]; then
    PATH="${PATH:+${PATH}:}$FZF_PREFIX/bin"
  fi

  # Auto-completion (interactive shells only)
  [[ $- == *i* ]] && source "$FZF_PREFIX/shell/completion.zsh" 2>/dev/null

  # Key bindings
  source "$FZF_PREFIX/shell/key-bindings.zsh" 2>/dev/null
fi
```

Key changes:
1. Guard the entire block with a check for brew command and fzf installation
2. Cache `$(brew --prefix)` in FZF_PREFIX variable (avoids multiple subshell calls)
3. Use FZF_PREFIX variable for all paths
4. Uncomment key-bindings sourcing (was commented in original)
  </action>
  <verify>
Run `zsh -c 'source ~/.config/zsh/zprofile && source ~/.config/zsh/plugins/fzf.zsh && echo $FZF_PREFIX'` - should output fzf prefix path.
Confirm file contains `brew --prefix` and no hardcoded `/opt/homebrew`.
  </verify>
