  <files>dot/index.ts</files>
  <action>
Add brewfile sync functionality following the established patterns from dependency checking:

1. Add types at the top of the file (near DependencyStatus):
```typescript
type BrewfilePackage = {
  name: string;
  type: 'formula' | 'cask';
  description?: string;
};

type BrewfileSyncStatus = {
  inBrewfileNotInstalled: BrewfilePackage[];
  installedNotInBrewfile: BrewfilePackage[];
};
```

2. Add parseBrewfile function:
- Read brewfile from `${config.dotfiles}/homebrew/brewfile` using Bun.file()
- Parse lines starting with `brew "` to extract formula names (handle tap paths like `oven-sh/bun/bun`)
- Parse lines starting with `cask "` to extract cask names
- Extract description from comment on previous line if present (lines starting with `# `)
- Ignore `tap` lines (those aren't packages to install)
- Return array of BrewfilePackage

3. Add getInstalledPackages function:
- Run `brew list --formula -1` to get installed formulae (one per line)
- Run `brew list --cask -1` to get installed casks (one per line)
- Use .nothrow().quiet() pattern from isToolInstalled
- Return array of BrewfilePackage with type set appropriately

4. Add checkBrewfileSync function:
- Call parseBrewfile and getInstalledPackages
- Compare brewfile packages against installed (find missing from system)
- Compare installed packages against brewfile (find untracked)
- For tap path formulae (e.g., `oven-sh/bun/bun`), compare against just the last segment (`bun`) when matching installed packages
- Return BrewfileSyncStatus

5. Add printBrewfileStatus function:
- Print "Brewfile sync:" header
- If inBrewfileNotInstalled is not empty:
  - Print "Not installed (in brewfile):" with each package name and type
  - Print "Install missing with: brew bundle install --file=~/.dotfiles/homebrew/brewfile"
- If installedNotInBrewfile is not empty:
  - Print "Untracked (not in brewfile):" with each package name and type
  - Do NOT suggest adding to brewfile (per requirements)
- If both empty, print "All synced" with checkmark

6. Integrate into doctor() function:
- After `printBrewInstallCommand(depStatus)` and the blank line
- Before "Load reviewed paths" comment
- Add:
```typescript
console.log("Checking brewfile sync...");
const brewfileStatus = await checkBrewfileSync(config);
printBrewfileStatus(brewfileStatus);
console.log("");
```

7. Export new functions for testing:
- Add parseBrewfile, getInstalledPackages, checkBrewfileSync to exports
- Add BrewfilePackage and BrewfileSyncStatus types to type exports
