**promptDotfilesLocation()**:
```typescript
import { createPrompt, createSelection } from 'bun-promptx';

export async function promptDotfilesLocation(): Promise<string> {
  const defaultPath = `${process.env.HOME}/.dotfiles`;

  const items = [
    { text: defaultPath, description: 'Default location' },
    { text: '[Enter custom path]', description: 'Specify a different location' },
  ];

  const result = createSelection(items, {
    headerText: 'Where are your dotfiles?',
  });

  if (result.error) throw result.error;

  if (result.selectedIndex === 1) {
    const { value, error } = createPrompt('Enter path: ');
    if (error) throw error;
    return expandPath(value);
  }

  return defaultPath;
}
```
- Validate path exists OR offer to create it
- Return absolute path with ~ expanded

**selectItems(items: Array<{text: string, description?: string}>, options?: {multi?: boolean})**:
```typescript
export function selectItems<T extends {text: string}>(
  items: T[],
  options?: { headerText?: string; multi?: boolean }
): T[] {
  if (options?.multi) {
    // Use createSelection with return of selected items
    // bun-promptx supports multi-select via shift+enter
    const result = createSelection(
      items.map(i => ({ text: i.text, description: (i as any).description })),
      { headerText: options.headerText, multiple: true }
    );
    if (result.error) return [];
    // Return selected items based on indices
    return result.selectedIndexes?.map(i => items[i]) ?? [];
  }

  const result = createSelection(
    items.map(i => ({ text: i.text, description: (i as any).description })),
    { headerText: options?.headerText }
  );
  if (result.error) return [];
  return [items[result.selectedIndex]];
}
```

**confirm(message: string)**:
```typescript
export function confirm(message: string): boolean {
  const items = [
    { text: 'Yes', description: 'Proceed' },
    { text: 'No', description: 'Cancel' },
  ];
  const result = createSelection(items, { headerText: message });
  if (result.error) return false;
  return result.selectedIndex === 0;
}
```
- Selection-based yes/no
- Default visual focus on 'No' for safety

**Flow:**

1. **Check existing state**:
   - If state.json exists with valid path, use confirm(): "Dotfiles already configured at X. Reconfigure?"
   - If no, exit

2. **Get dotfiles location**:
   - If `--from` provided: clone repo to ~/.dotfiles (or prompted location)
   - Else: promptDotfilesLocation()

3. **Check for existing config**:
   - If dot.config.json or dot.config.ts exists, use confirm(): "Found existing config. Use it?"
   - If yes, load and proceed to step 6
   - If no, continue to scan

4. **Scan for existing dotfiles**:
   - Run scanCommonDotfiles(home)
   - Display found dotfiles
   - Use selectItems with multi=true for checkbox-style selection of which dotfiles to migrate
   - Also offer "Select all" and "Select none" quick options

5. **Generate config**:
   - Build links map from selected dotfiles
   - Ask about autoCommit preference using confirm() (default: yes)
   - Write dot.config.json to dotfiles folder

6. **Initialize git** (if not already):
   - Check if .git exists
   - If not, run `git init`
   - If has files to track, offer initial commit

7. **Preview and confirm**:
   - Call previewSymlinks()
   - If conflicts and not --force, abort
   - Use confirm(): "Create these symlinks?"

8. **Execute**:
   - Move original files to dotfiles folder (if migrating)
   - Create symlinks using existing install logic
   - Save state with dotfilesPath

9. **Success message**:
   - Print summary of what was done
   - Print "Run 'dot doctor' to verify setup"

**Update index.ts**:
- Add 'init' case to command switch
- Parse --from and --force flags for init
- Allow init to run even when no state exists (skip initializeDot check)
