**Create dot/tests/track.test.ts** with tests for config write functions:

```typescript
import { describe, it, expect, beforeEach, afterEach } from "bun:test";
import { writeConfig, updateConfigLinks, loadConfig } from "../src/config";
import { mkdtemp, rm } from "fs/promises";
import { tmpdir } from "os";
import { join } from "path";

describe("config write functions", () => {
  let tempDir: string;

  beforeEach(async () => {
    tempDir = await mkdtemp(join(tmpdir(), "dot-test-"));
  });

  afterEach(async () => {
    await rm(tempDir, { recursive: true, force: true });
  });

  it("writeConfig creates valid JSON file", async () => {
    const config = { links: { "zsh/zshrc": "~/.zshrc" } };
    await writeConfig(tempDir, config);

    const loaded = await loadConfig(tempDir);
    expect(loaded).toEqual(config);
  });

  it("updateConfigLinks adds new link to existing config", async () => {
    // Create initial config
    await writeConfig(tempDir, { links: { "git/gitconfig": "~/.gitconfig" } });

    // Add new link
    const updated = await updateConfigLinks(tempDir, {
      source: "zsh/zshrc",
      target: "~/.zshrc"
    });

    expect(updated.links["git/gitconfig"]).toBe("~/.gitconfig");
    expect(updated.links["zsh/zshrc"]).toBe("~/.zshrc");
  });

  it("updateConfigLinks creates new config if none exists", async () => {
    const updated = await updateConfigLinks(tempDir, {
      source: "zsh/zshrc",
      target: "~/.zshrc"
    });

    expect(updated.links["zsh/zshrc"]).toBe("~/.zshrc");

    // Verify file was created
    const loaded = await loadConfig(tempDir);
    expect(loaded).toEqual(updated);
  });
});
```

**track.ts** - Track command:

```typescript
export type TrackOptions = {
  as?: string;  // --as zsh/zshrc
  force?: boolean;
};

export async function track(
  targetPath: string,
  dotfilesPath: string,
  config: DotConfig,
  options: TrackOptions
): Promise<void>
```

**DotConfig parameter wiring (IMPORTANT):**
The `config` parameter is the DotConfig type from types.ts, which includes:
- `links: LinkMap` - existing symlink mappings
- `autoCommit?: boolean` - whether to auto-commit after track (default true)

Access autoCommit like this:
```typescript
// config.autoCommit defaults to true if undefined
const shouldCommit = config.autoCommit !== false;

// Later in the function, after file operations:
if (shouldCommit) {
  // git add and commit
}
```

**Flow:**

1. **Validate target**:
   - Resolve targetPath to absolute
   - Verify file/directory exists
   - If it's a symlink, error "Already a symlink. Nothing to track."

2. **Determine destination**:
   - If `--as` provided, use that as relative path in dotfiles
   - Else, interactive selection:
     - List existing top-level folders in dotfiles (git, zsh, tmux, etc.)
     - Option: "[new folder]"
     - Option: "[root]" for top-level
     - After folder selection, prompt for filename (default: basename of target)
   - Compute full destination: `${dotfilesPath}/${folder}/${filename}`

3. **Check for conflicts**:
   - If destination exists in dotfiles repo:
     - If --force: backup to .bak and continue
     - Else: prompt with options:
       - Replace (move current to trash/backup)
       - Backup and replace (keep .bak)
       - Cancel
   - If source is already in config with different target: warn and confirm

4. **Preview and confirm**:
   - Show: "Will move: {target} -> {destination}"
   - Show: "Will create symlink: {target} -> {destination}"
   - If autoCommit enabled (check `config.autoCommit !== false`): "Will commit: 'Add {filename}'"
   - Ask confirmation unless --force

5. **Execute**:
   - Create destination directory if needed: `mkdir -p dirname(destination)`
   - Move file: `mv target destination`
   - Create symlink: `symlink(destination, target)`
   - Update config with new link using `updateConfigLinks` from config.ts
   - If `config.autoCommit !== false`: `git add destination dot.config.json && git commit -m "Add {filename}"`

6. **Success message**:
   - Print what was done
   - Print "Symlink created: {target} -> {destination}"

**Update index.ts:**

- Track requires initialized dot (config must exist)
