**move.ts** - Move command:

```typescript
export type MoveOptions = {
  force?: boolean;
};

export async function move(
  newPath: string,
  currentPath: string,
  config: DotConfig,
  options: MoveOptions
): Promise<void>
```

**Flow:**

1. **Validate new path**:
   - Resolve to absolute path (expand ~)
   - If path exists and not empty:
     - If --force: warn and continue
     - Else: error "Destination exists and is not empty. Use --force to override."
   - If path is inside current dotfiles: error "Cannot move to subdirectory of itself"

2. **Preview changes**:
   - Print "Will move: {currentPath} -> {newPath}"
   - List all symlinks that will be updated
   - Ask confirmation unless --force

3. **Execute move**:
   - Create parent directory if needed: `mkdir -p dirname(newPath)`
   - Move folder: use `mv` command or fs.rename
   - If rename fails (cross-device), fall back to copy+delete

4. **Update symlinks**:
   - For each link in config:
     - Compute old source: `currentPath + relative`
     - Compute new source: `newPath + relative`
     - Remove old symlink
     - Create new symlink pointing to new source
   - Track failures and report at end

5. **Update state**:
   - Save new dotfilesPath to state.json

6. **Update config paths** (if config uses absolute paths):
   - This shouldn't be needed since config uses relative paths
   - But scan for any absolute paths and warn if found

7. **Verify**:
   - Quick check that key symlinks work
   - Print success message with new location
