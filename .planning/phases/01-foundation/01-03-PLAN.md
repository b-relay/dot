Requirements:
1. Type definition:
```typescript
export type InstallState = {
  version: string;           // State schema version (for migrations)
  startedAt: string;         // ISO timestamp when install started
  completedSteps: string[];  // Step IDs that are complete
  totalSteps: number;        // Total steps in this install
  status: 'in-progress' | 'completed' | 'failed';
};
```

2. Functions:
- `loadState(statePath: string): Promise<InstallState | null>` - Returns null if no state file
- `saveState(statePath: string, state: InstallState): Promise<void>` - Uses write-file-atomic with fsync:true
- `createInitialState(totalSteps: number): InstallState` - Creates fresh state
- `markStepComplete(state: InstallState, stepId: string): InstallState` - Returns updated state (immutable)
- `isStepComplete(state: InstallState, stepId: string): boolean` - Checks if step already done

3. State file location: `{dotfiles}/.install-state.json`
   - Store in dotfiles repo so state travels with repo (as recommended in RESEARCH.md)

4. Step ID format: `symlink:{target}` (e.g., `symlink:/Users/clay/.zshenv`)

Use write-file-atomic for atomic writes (prevents corruption on Ctrl+C).
