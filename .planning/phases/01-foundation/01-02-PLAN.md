  <action>
Create `src/lib/backup.ts` with backup functionality.

Requirements:
1. `backupFile(filePath: string, backupDir: string, manifest: BackupManifest): Promise<string>`
   - Creates backup directory if needed
   - Copies file with timestamp in name: `{filename}.{ISO-timestamp}.backup`
   - Adds entry to manifest
   - Returns backup path
   - Logs the backup operation using logger from Plan 01

2. `loadBackupManifest(manifestPath: string): Promise<BackupManifest>`
   - Loads existing manifest or returns empty one
   - Manifest stored at `{backupDir}/.backup-manifest.json`

3. `saveBackupManifest(manifestPath: string, manifest: BackupManifest): Promise<void>`
   - Writes manifest atomically using write-file-atomic

4. Type definitions:
```typescript
export type BackupEntry = {
  original: string;    // Original file path
  backup: string;      // Backup file path
  timestamp: string;   // ISO timestamp when backed up
};

export type BackupManifest = {
  backups: BackupEntry[];
};
```

Use ISO timestamp format with colons/periods replaced for filesystem safety: `2026-01-27T14-30-45-123Z`

Use the logger from src/lib/logger.ts for logging backup operations.
