**Scanner false positive on conditional checks** (documented, low severity)

The scanner uses simple regex which could flag conditional file checks as hardcoded paths on Intel. This is:
- Documented in code (`dot/index.ts:476-484`)
- Not affecting current codebase (zprofile uses `/opt/homebrew/bin/brew` and `/usr/local/bin/brew` which don't match the Intel pattern)
- A future enhancement, not a blocker
